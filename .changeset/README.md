# Changesets

This folder has been automatically generated by [Changesets](https://github.com/changesets/changesets).

To record a change for the next release, run:

```bash
npm run changeset
```

Pick the bump type (major/minor/patch) and write a short summary. Commit the
generated `.changeset/*.md` file alongside your change. On merge to `main`, the
release workflow opens a "Version Packages" PR that consumes these files, bumps
the version (and syncs `.claude-plugin/plugin.json`), and updates the changelog.
